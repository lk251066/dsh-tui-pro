# Project Status

[`@lk251066/dsh-tui@1.8.1`](https://www.npmjs.com/package/@lk251066/dsh-tui/v/1.8.1) is the current release. Its source, artifact, public-host, clean-profile, and real-PTY verification is recorded in [TESTING.md](TESTING.md).

The TUI is a multi-session terminal workbench for DeepSeek Harness. A durable Assistant remains outside project workspaces, while manually maintained project sessions stay grouped by workspace in the fixed sidebar. Only the transcript scrolls; the editor, plan, status, model, context usage, and active sessions remain visible.

The public project page leads with this session workflow, a deterministic demonstration generated through the real TUI test composition, and verified `dsh` and `npx` installation paths. GitHub Issues, Discussions, private vulnerability reporting, repository topics, npm, Releases, and dshfind provide the public support and discovery entry points.

[CHANGES.md](CHANGES.md) owns current runtime behavior. [DEVELOPMENT.md](DEVELOPMENT.md) defines contributor setup, [CONTRIBUTING.md](CONTRIBUTING.md) defines the contribution path, and [TESTING.md](TESTING.md) defines required verification evidence.
