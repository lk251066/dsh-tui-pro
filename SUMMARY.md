# Project Status

`@lk251066/dsh-tui@1.4.0` is the current release target. The latest public package remains [`1.3.0`](https://www.npmjs.com/package/@lk251066/dsh-tui/v/1.3.0) until the source, artifact, public-host, and PTY checks complete.

Version `1.4.0` keeps the fixed framed workbench and durable active workspace sessions. Short choices use the fixed bottom area without popup borders. `/sessions` replaces only the left chat area, leaving the outer frame and active-workspace sidebar fixed; current-directory startup still resumes an active project session or creates and activates one.

[CHANGES.md](CHANGES.md) owns current behavior. [REPAIR_PLAN.md](REPAIR_PLAN.md) records release readiness, and [TESTING.md](TESTING.md) defines the required evidence.
