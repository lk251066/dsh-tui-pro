# Project Status

[`@lk251066/dsh-tui@1.5.0`](https://www.npmjs.com/package/@lk251066/dsh-tui/v/1.5.0) is the current release. Its source, artifact, public-host, and real PTY checks pass.

Version `1.5.0` keeps the fixed framed workbench and durable active workspace sessions. Enter steers the running turn, Tab queues the next turn, double Escape branches from a current-conversation checkpoint, and `Ctrl+PageUp` or `Ctrl+PageDown` switches active sessions. Complete history and built-in information views replace only the left chat area, leaving the outer frame and active-workspace sidebar fixed.

[CHANGES.md](CHANGES.md) owns current behavior. [REPAIR_PLAN.md](REPAIR_PLAN.md) records release readiness, and [TESTING.md](TESTING.md) defines the required evidence.
