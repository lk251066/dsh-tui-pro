# Security Policy

## Supported releases

Security fixes target the latest published release of `@lk251066/dsh-tui`. Upgrade to the current npm version before reporting a problem that may already be resolved.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting flow from the repository Security tab. Do not open a public issue for a vulnerability that could expose credentials, session content, local files, command execution, or permission controls.

Include the affected plugin and dsh versions, operating system, terminal, reproduction steps, impact, and the smallest proof of concept. Remove real API keys, private paths, and session data.

Ordinary bugs without security impact belong in the public [issue tracker](https://github.com/lk251066/dsh-tui-pro/issues/new/choose).
